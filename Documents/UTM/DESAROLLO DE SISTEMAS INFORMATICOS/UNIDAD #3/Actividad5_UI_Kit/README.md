# Design System - Help Desk

## Descripción

Este proyecto corresponde a la Actividad #5 de la asignatura Desarrollo de Sistemas Informáticos de la Universidad Técnica de Manabí.

El objetivo es desarrollar una librería de componentes de interfaz de usuario (UI Kit) utilizando HTML5 y CSS3, con el fin de establecer una línea gráfica para un sistema de gestión de incidentes (Help Desk).

---

## Tecnologías utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

---

```
Actividad5_UI_Kit/

```

---

## Componentes desarrollados

El proyecto incluye los siguientes componentes:

- Botón Primario
- Botón Secundario
- Botón de Peligro
- Campo de texto (Input)
- Lista desplegable (Select)
- Tarjeta (Card)
- Alertas o Badges (Alta, Media y Baja)

---

## Funcionalidades

- Uso de variables CSS para la gestión de colores.
- Diseño moderno mediante CSS3.
- Componentes reutilizables.
- Aplicación del modelo Box Model.
- Uso de selectores y pseudo-clases (:hover y :focus).
- Código organizado y fácil de mantener.

---

## Instrucciones de uso

1. Descargar o clonar el proyecto.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo **index.html** en un navegador web.
4. Visualizar los componentes del Design System.
