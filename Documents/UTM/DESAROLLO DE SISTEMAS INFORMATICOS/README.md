# Sistema de Gestión de Incidentes (Help Desk) - Backend y Base de Datos

Proyecto desarrollado para la **Universidad Técnica de Manabí** como parte de la Actividad #8 de la unidad de Desarrollo de Sistemas Informáticos.

##  Tecnologías Utilizadas
* **Backend:** Node.js con Express.
* **Base de Datos:** PostgreSQL / pgAdmin.
* **Control de Versiones:** Git y GitHub.
* **Pruebas de API:** Postman.

---

##  Estructura del Proyecto
El repositorio se encuentra organizado de la siguiente manera:
```text
sistema-incidentes/
│

├── frontend/       # Interfaz de usuario (si aplica)
